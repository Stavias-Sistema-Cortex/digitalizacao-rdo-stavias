## Decisão

- Decisão central: arquitetura monorepo com `apps/api` Spring Boot e `apps/web` React PWA.
- Justificativa: operação de campo precisa offline-first, por isso PWA + IndexedDB + sync server-side.
- Banco escolhido: MySQL com Flyway, evitando schema drift e mantendo compatibilidade com fontes externas MySQL.
- API: REST JSON com `/api/*`, autenticação JWT e autorização no servidor.
- Integrações: importações batch de ZLD/Academy por JDBC, isoladas por env vars.
- IA: Stav.IA com LLM local/OpenAI-compatible, com fallback/determinação local para reduzir dependência externa.
- Trade-off importante: PWA offline aumenta complexidade de conflito/sync, mas atende canteiro/obra com conectividade instável.
- Risco técnico: autorização por obra ainda merece uma ACL explícita própria, não inferida de alocação operacional.
- Decisão operacional: Compose usa API em `8081` para não conflitar com API local direta em `8080`.
- Segurança: segredos só por env vars, JWT secret obrigatório, imports manuais desligados por padrão.
