# CortexUI 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a coherent CortexUI 2.0 shell and fail-safe RDO creation
experience without changing backend behavior.

**Architecture:** `CortexShell` provides its authenticated controls through a
small React context. A shared `CortexPageHeader` renders those controls alongside
real page actions, and compatibility wrappers keep existing page APIs stable.
Desktop shell scrolling is isolated to the content column; RDO API envelopes
are validated before persistence or presentation.

**Tech Stack:** React 18, TypeScript, React Router, Vitest, Testing Library,
plain CSS, IndexedDB.

## Global Constraints

- Do not change backend source or API semantics for CortexUI 2.0.
- Do not introduce hardcoded business records, metrics, IDs, or placeholder data.
- Preserve offline persistence, automatic sync, authorization, and session scope.
- Use the existing local Poppins assets; add no network font dependency.
- Respect visible keyboard focus and `prefers-reduced-motion`.
